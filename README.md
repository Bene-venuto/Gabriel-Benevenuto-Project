## 🖥️ Sobre o projeto

Este é o meu site pessoal — vitrine, currículo e canal de contato em um só lugar. Construído com **HTML, CSS e JavaScript puro**, sem frameworks e sem back-end, por decisão consciente: antes de depender de uma biblioteca que resolve tudo por mim, quis entender de verdade o que cada linha de código faz.

A identidade visual parte de um conceito único — uma **ficha de ordem de serviço de fábrica** — que conecta a narrativa da minha transição de carreira com o visual do site: o cartão de abertura (hero) é desenhado como um ticket de produção, com campos como Peça, Setor, Responsável e uma barra de status.

## ✨ Funcionalidades

- Layout 100% responsivo (desktop, tablet e mobile)
- Navegação por âncoras com rolagem suave
- Seção de projetos com um case real em destaque e projetos conceito claramente identificados
- Formulário de contato funcional via `mailto:` (sem back-end)
- Ano do rodapé atualizado automaticamente via JavaScript
- Pequeno easter egg no console do navegador (abra o DevTools 👀)
- Animação de entrada respeitando `prefers-reduced-motion`

## 🚀 Rodando localmente

Não é preciso instalar nada — é HTML/CSS/JS puro:

```bash
# clone o repositório
git clone https://github.com/bene-venuto/bene-venuto.github.io.git

# entre na pasta
cd bene-venuto.github.io

# abra o index.html no navegador
# (ou use a extensão Live Server no VS Code para live reload)
```
