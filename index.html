Sobre mim

Antes da programação, minha rotina era outra: ordens de produção, prazos apertados, equipes para coordenar e processos para manter de pé. Foi ali que aprendi, na prática, o que significa resolver problemas com recursos limitados e tempo curto.

Hoje aplico essa mesma lógica ao desenvolvimento de software: entendo o problema antes de abrir o editor, penso em como o sistema será usado no dia a dia, e só depois escrevo a primeira linha de código.

Estou focando meus estudos e projetos em desenvolvimento FullStack - HTML, CSS e JavaScript como base, evoluindo em React, Node.js e banco de dados relacionais.

Como eu trabalho

Um processo, não um atalho.

01

Entendo o problema

Antes de qualquer linha de código, entendo o que a aplicação precisa resolver e para quem.

02

Planejo

Estruturo funcionalidades, modelo de dados e a arquitetura da aplicação.

03

Desenvolvo
